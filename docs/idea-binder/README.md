# Idea Binder Documents

Use these files to keep each AI idea documented in a printable, trackable format.

## Files

- `GIG_README_TEMPLATE.md` — copy this for each gig/idea.
- `WORKFLOW_DIAGRAM_TEMPLATE.md` — horizontal n8n-style diagram blocks you can paste into each README.
- `morning-brief-automation/README.md` — active gig record for Morning Brief Automation.

## Suggested workflow

1. Copy `GIG_README_TEMPLATE.md` into a new idea folder.
2. Fill in the date fields first (`Created`, `Last Updated`).
3. Paste a horizontal workflow from `WORKFLOW_DIAGRAM_TEMPLATE.md`.
4. Print the completed README for your binder.

## Quick print note

For iPhone: open the markdown file in GitHub, copy text, paste into Notes, then Share > Print.
